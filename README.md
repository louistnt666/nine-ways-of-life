# 人生九种 · Nine Ways of Life

用 36 个日常选择，探索你更常采用的九种生活态度。一款无需注册、在浏览器内完成计分的中文趣味测试，支持手机和电脑。

> **[在线体验](https://louistnt666.github.io/nine-ways-of-life/)** · GitHub Pages 项目网站。

## 项目特点

- **36 道原创情境题**：围绕关系、选择、工作、快乐与意义，约 5—7 分钟完成。
- **九种生活态度**：享乐、利己、犬儒、现实、利他、理想、虚无、存在与浪漫主义。
- **完整结果报告**：九维雷达图、三重倾向、信条、日常表现、关系特点、能量消耗与行动建议。
- **同分如实呈现**：并列展示，不强行指定唯一类型；可切换阅读九种解析。
- **本机保存进度**：支持返回修改与继续答题，报告在网页内阅读。
- **轻量静态网页**：无需安装依赖或连接外部字体、脚本服务，兼容窄屏与桌面布局。

## 计分方式

每题四个选项分别对应不同倾向。每种倾向在题库中出现 16 次，选中一次记 1 分。36 次选择的总分为 36；各维度显示为 0—16 分。前三个不同得分层级构成三重倾向，同分并列。

分数是本题库的选择次数，不是人格百分比、契合准确率或经过验证的心理测量结果。

## 使用

下载 `index.html` 后直接用浏览器打开。键盘 1—4 可选择答案。答题记录保存在当前浏览器，换设备或更换网站地址不会自动同步。

## GitHub Pages 发布

1. 使用公开仓库 `louistnt666/nine-ways-of-life`。
2. 将 `index.html`、`.nojekyll` 和本文件放在 `main` 分支根目录。
3. Settings → Pages → Deploy from a branch → main → /(root) → Save。
4. 等待部署成功，再检查页面、答题、结果和手机布局。

## 文件结构

- `index.html`：页面样式、原创题库、计分逻辑和完整解析，单文件运行。
- `.nojekyll`：禁用 Jekyll 处理，直接提供静态文件。
- `README.md`：项目介绍与使用说明。

## 隐私与边界

应用代码不上传答题记录，不使用分析或广告脚本；网站托管方仍可能记录常规访问日志。此公开版本不限制访问者地区。

仅供娱乐和自我探索，不是心理诊断，也不是 MBTI 或九型人格量表。不要据此判断个人能力、疾病、职业适配或关系成败。
